# Какие текстуры/иконки нужны от вас

Всё, что можно было нарисовать/собрать из уже привезённых моделей, — сделано.
Ниже **только то, чего физически нет**: этих файлов нет в репозитории, и без них
предметы показываются заглушкой (эмодзи/серый силуэт).

## Формат

| Параметр | Значение |
|---|---|
| Формат | PNG, RGBA (прозрачный фон обязателен) |
| Размер | **1024×1024** (как все текущие `assets/icons/*.png`) |
| Стиль | как у существующих иконок: объёмный предмет, лёгкая снежная крошка, холодный свет |
| Куда класть | `app-winterforest/src/main/assets/icons/` |

## 1. Иконки редкого лута из военных ящиков (3 шт.) — **самое важное**

Это новые предметы, которые выпадают только из военных ящиков; сейчас в хотбаре
и рюкзаке у них заглушка «📦».

| Файл | Предмет | Что нарисовать |
|---|---|---|
| `icon_soldier_ration.png` | Сухпай (`SOLDIER_RATION`) | Плоский армейский паёк в серо-зелёной упаковке, полосатая застёжка, пара консервных банок рядом |
| `icon_hunting_knife.png` | Охотничий нож (`HUNTING_KNIFE`) | Нож с деревянной рукоятью, кожаные ножны, сталь с бликом |
| `icon_first_aid_kit.png` | Полевая аптечка (`FIRST_AID_KIT`) | Брезентовый армейский подсумок с красным крестом, бинт/жгут сверху |

## 2. Иконки провианта из обычных ящиков (2 шт.)

Обычный ящик выдаёт ткань и, реже, еду. Ягоды и мясо **уже есть** — не нужны.

| Файл | Предмет | Что нарисовать |
|---|---|---|
| `icon_fish_smoked.png` | Копчёная рыба (провиант из ящика) | Тушка копчёной рыбы на щепе, золотисто-янтарная, лёгкий дымок |
| `icon_ration_can.png` | Консервная банка (провиант из ящика) | Мятая жестяная банка без этикетки, открытая крышка «ключом» |

> Если решите не рисовать — я оставлю выдачу рыбы/консервов как обычные «Рыба»/«Мясо»
> с уже существующими иконками, ничего не сломается.

## Куда это попадёт после привоза

1. `icon_soldier_ration.png` → иконка в хотбаре, рюкзаке, коллекции находок и всплывающем сообщении «Добыт трофей».
2. `icon_hunting_knife.png` → то же + бейдж «+3 урона зверю» в описании.
3. `icon_first_aid_kit.png` → то же + кнопка «Применить» (лечит +45 HP).
4. Если привезёте `models/hunting_knife/`, нож появится в руке при экипировке.

## Как передать

Только **через GitHub-репозиторий** (в чат загружать бесполезно — дважды приходили
чужие файлы, скриншоты Yandex Ads вместо моделей). Достаточно запушить PNG-файлы
в `assets/icons/` (или модели в `assets/models/`), я подхвачу, пропишу пути и
пересоберу APK.
